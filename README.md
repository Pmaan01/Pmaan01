## 🚀 Featured Projects  

### 🅿️ [Parkify – Smart City Parking Availability App](https://github.com/Pmaan01/Parkify-Web-App)
A full-stack web application to predict and display real-time parking availability using user-reported data and external APIs.  
**Tech Stack:** React.js, JavaScript, Node.js, MongoDB, Express.js, Google Maps API  
**Highlights:**  
- Interactive map with **React Leaflet** for real-time parking markers.  
- Google Maps navigation with return prompt for parking confirmation.  
- Crowdsourced spot reporting with a **reward points** system.  
- Unified API and MongoDB data into a **single backend schema**.  
- **Deployed:** Frontend on Vercel, Backend on Render.  
[🔗 Live Demo](https://parkify-web-app-xi.vercel.app/)
